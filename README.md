# 역진자 제어 시뮬레이션

웹 기반 역진자(Inverted Pendulum) 제어 시뮬레이션입니다. 레일 위에서 움직이는 카트에 매달린 펜듈럼을 제어하여 수직으로 세우고 균형을 유지합니다.

## 기능

- **물리 시뮬레이션**: Runge-Kutta 4차 적분법을 사용한 정확한 물리 엔진
- **제어 알고리즘**: 에너지 기반 스윙업 + PID 밸런싱
- **실시간 시각화**: Canvas 기반 부드러운 애니메이션
- **텔레메트리**: 펜듈럼 각도, 카트 위치, 제어 모드, 제어력 실시간 표시

## 사용 방법

1. `index.html` 파일을 브라우저에서 엽니다
2. "시작" 버튼을 클릭하여 시뮬레이션을 시작합니다
3. 카트가 좌우로 움직이며 펜듈럼을 수직으로 세우고 균형을 유지합니다
4. "종료" 버튼을 클릭하면 제어가 중단되고 펜듈럼이 중력에 의해 떨어집니다

## 기술 스택

- HTML5 Canvas
- Vanilla JavaScript
- CSS3 (글래스모피즘, 그라데이션)

## 파일 구조

```
05 pendulum/
├── index.html      # 메인 HTML 파일
├── styles.css      # 스타일링
├── physics.js      # 물리 엔진 및 제어 알고리즘
├── renderer.js     # Canvas 렌더링
└── main.js         # 메인 애플리케이션 로직
```

## 제어 이론

이 시뮬레이션은 제어 이론의 고전적인 문제인 역진자 문제를 구현합니다:

1. **스윙업 단계**: 펜듈럼이 아래에 있을 때 에너지 기반 제어로 진동시켜 위로 올립니다
2. **밸런싱 단계**: 펜듈럼이 거의 수직이 되면 PID 제어로 균형을 유지합니다
